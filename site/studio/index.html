유튜브 API 키

키는 지금 쓰는 이 기기의 브라우저에만 저장돼요. 휴대폰과 PC를 둘 다 쓰면 각각 한 번씩 넣어주세요.

키 발급 방법 (무료, 5분)

  1. console.cloud.google.com에 구글 계정으로 로그인 (약관 동의)
  2. 상단의 프로젝트 선택 → 새 프로젝트 → 이름 예: shorts-studio → 만들기
  3. 왼쪽 메뉴 API 및 서비스 → 라이브러리 → YouTube Data API v3 검색 → 사용
  4. API 및 서비스 → 사용자 인증 정보 → + 사용자 인증 정보 만들기 → API 키
  5. 만들어진 키를 눌러 키 제한 설정 (중요, 남이 키를 못 쓰게):
    · 애플리케이션 제한: 웹사이트 → https://joopjwi.github.io/* 추가
    · API 제한: 키 제한 → YouTube Data API v3만 체크 → 저장
  6. 키를 복사해서 위 칸에 붙여넣고 저장 → 연결 테스트

결제 정보 등록은 필요 없어요. 하루 무료 한도는 10,000 단위로, 검색 한 번에 약 100이 들어요. '오늘의 추천'은 약 600이라 하루 10번 이상 돌려도 충분해요. 한도는 한국 시간 오후 4~5시쯤(미국 태평양 자정) 초기화돼요.

원본 고르는 기준

  1. 사건이 있는 영상: 처음 3초 안에 "어? 왜?"가 생기고 끝에 반전이 있는 것 (예: 물범을 세척 → 알고 보니 진짜 물범)
  2. 말이 없어도 이해되는 영상: 원본 대사에 의존하면 재가공이 어려워요
  3. 15~90초 분량: 필요한 장면만 써도 50초 쇼츠가 나오는 길이
  4. 피할 것: 방송사·영화·뮤직비디오 클립, 일반인 얼굴이 크게 나오는 영상, 사고 피해자가 나오는 영상
  5. CC 라이선스 영상은 출처만 밝히면 재사용이 허락된 영상이라 가장 안전해요

휴대폰 ↔ PC 연동

찜·사용·지운 후보, 업로드 체크(보관함), 레퍼런스가 모든 기기에서 똑같이 보이게 해요. 기기마다 아래 연동 키를 한 번씩 넣어주세요.

이 기기에 넣은 유튜브 API 키와 연동 키를 담은 링크예요. 카톡 '나에게 보내기'로 보내서 휴대폰에서 누르면 사파리(기본 브라우저)가 열리면서 두 키가 한 번에 들어가요. 링크에 키가 들어 있으니 다른 사람에게는 보내지 마세요.

연동 키 만드는 법 (GitHub, 3분)

  1. PC에서 github.com/settings/personal-access-tokens/new 열기 (joopjwi 계정 로그인)
  2. Token name: 딸깍공장 연동 · Expiration: 1년(또는 원하는 기간)
  3. Repository access → Only select repositories → joopjwi/joopjwi.github.io 선택
  4. Permissions → Repository permissions → Contents → Read and write
  5. 맨 아래 Generate token → 나온 키 복사 → 위 칸에 붙여넣고 저장 · 연동
  6. 휴대폰에서도 이 페이지 설정 탭에 같은 키를 한 번 넣어주세요 (카톡 나에게 보내기 등으로 옮기면 편해요)

키는 이 기기 브라우저에만 저장돼요. 연동 데이터(찜·레퍼런스 링크·업로드 기록)는 저장소의 별도 공간(studio-sync)에 저장되고, 저장소가 공개라 링크를 아는 사람은 볼 수 있어요. 유튜브 API 키나 연동 키는 올라가지 않아요.

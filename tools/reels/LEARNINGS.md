# 줍쥐 릴스 성과 학습 노트

매일 아침 성과 분석(PLAYBOOK 0-1단계) 후 김신혜가 갱신한다. 위에서부터 최신순.
각 항목은 "근거(수치) → 다음에 적용할 것" 형태로 짧게. 30줄이 넘으면 오래된 것을 요약해 줄인다.

## 현재 적용 중인 원칙
- 바이럴 후보: 궁금한 템 2~3 + 생필품 1~2, 계절성 우선
- 첫 3초 이탈이 매우 높음(11/16 81.4%, 11/17 85.7%) → 인트로 첫 문장을 1번 상품 궁금증 질문으로 시작 (일반 문구 "만원도 안 하는 ~"로 시작 금지)
- 인트로는 2줄 이내로 짧게 → 2초 안에 1번 상품 진입 (11/17 인트로 3줄은 평균 시청 2.6초로 오히려 하락)
- 게시는 아침 07:45~09:00 중 Metricool 최적 시각 (11/17·11/19 기준 09시대가 가장 높음)
- 2줄 질문형 인트로 + '사진만 봐도 궁금한 1번' + 계절 공감템 조합 유지 (평균 시청 2.6→3.2→3.4초, 3초 이탈 86.1→81.1→78.7%, 11/19 첫 저장)

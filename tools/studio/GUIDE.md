# 원본 작업실 — 해외 원본 쇼츠 제작 지침

사용자가 정한 고정 지침. 모든 편에 적용한다.

## 포맷
- 1080×1920, 검은 배경 / 상단 제목 2줄(1줄 흰색, 2줄 노란색, 메모먼트 꾹꾹체(굵게, 화면 폭 약 87%·약 106px), 검은 외곽선) / 가운데 영상 띠 / 영상 하단에 한 줄 키네틱 자막(핵심 단어만 노란색) / 영상 아래 작게 출처
- 스토리텔링형 나레이션: 궁금증 → 전개 → 반전 → 도발 질문 엔딩
- 원본 소리는 쓰지 않음. 장면별 크롭·줌·속도·색감 재구성, 필요한 장면만 사용 (공정이용 방향)

## 음성 (ElevenLabs, 사용자 계정)
- 목소리: SK - Friendly & Mid-High Pitch (`vn80HZNY7EsdYzoFRYZm`) 고정 — 2026-11-19 확정 (Su - Casual은 어색해서 제외)
- 호흡·쉼은 0.2초로 커트, 공백 최대한 제거 (tts_eleven.py MAX_GAP=0.2)
- 효과음·BGM도 ElevenLabs로 생성 (studio-audio 워크플로)

## 자막
- 반드시 단어 또는 의미 단위로 끊는다. 단어 중간에서 줄을 나누지 않는다 (예: "했 / 습니다" 금지)
- 한 줄씩, 화면 폭을 넘으면 글자 크기를 줄여서 맞춘다 (줄을 쪼개지 않음)
- 조사·어미가 다음 줄로 혼자 떨어지지 않게, 의미가 끝나는 곳(쉼표·문장 끝·구 단위)에서 끊는다

## 효과음
- 슬라이드 휘슬처럼 높은 음 효과음은 작게(볼륨 0.15 수준) — 크면 거슬림 (2026-11-19 피드백)

## 출처
- 화면 출처 표기 위치: 하단 채널명(@아이디) 줄 오른쪽(약 x725, y1580), 작게
- 상단 제목은 영상 띠 바로 위에 붙게 (1줄 y≈282, 2줄 y≈392)
- 출처를 아는 영상만 설명란(원본 채널명·링크)과 화면에 표기. 출처를 모르면 설명란·화면 모두 출처 줄 없이 아예 미표기 (사용자 결정, 2026-11-19)
